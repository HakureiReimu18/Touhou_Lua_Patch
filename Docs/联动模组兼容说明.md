# 联动模组兼容说明（武器伤害与防具抗性设置）

> 面向「东方潜渊行动组 Lua 补丁」以外的模组作者：**不需要写任何代码**，只要在你自己的模组里放一个
> `Config/damage_settings.xml`，你的武器/防具就会被纳入玩家可调的倍率体系（伤害 / 穿甲 / 防御）。

## 1. 放哪儿

```
<你的模组>/
  Config/
    damage_settings.xml      ← 只要这个文件
```

- 文件名固定为 `damage_settings.xml`；**所有已启用内容包**里的同名文件都会被读取并按内容包加载顺序合并（后加载的覆盖先加载的）。
- 不需要 `filelist.xml` 登记（LuaCs 与本模组都是按目录扫描的）；也不要包 `<Override>` 标签（这是配置，不是内容覆盖）。
- 玩家侧无需任何设置；你的模组和本模组同时启用即生效。

## 2. 三种最常见的写法

### A. 把物品加进已有分组（最省事）

```xml
<?xml version="1.0" encoding="utf-8"?>
<DamageSettings version="1">
  <!-- 只写 <Group id>，不写属性 → 保留该分组已有的名字/类型/默认值，只往里加物品 -->
  <Group id="exclusive">            <!-- 专属武器：159+ 件东方武器/子弹 -->
    <Item id="my_exclusive_bullet"/>
    <Item id="my_exclusive_sword"/>
  </Group>
  <Group id="general">              <!-- 泛用武器 -->
    <Item id="my_general_bullet"/>
  </Group>
  <Group id="divingsuit">           <!-- 潜水服（防具组，只吃防御倍率） -->
    <Item id="my_diving_suit"/>
  </Group>
</DamageSettings>
```

可用分组 id：`exclusive`（专属武器）、`general`（泛用武器）、`turret`（舰炮炮塔弹药）、
`divingsuit`（潜水服）、`hyouibana`（凭依武装）、`headwear`（装束头饰）。
**武器组**吃 `damage` / `pen`；**防具组**吃 `def`（写错轴会被拒绝并给出提示）。

### B. 按 tag 收录（物品多、不想逐个列 id）

```xml
<Group id="general">
  <Tag name="my_mod_danmu"/>        <!-- 所有带这个 tag 的物品自动纳入 -->
</Group>
```

tag 从物品的 `tags="…"` 属性里匹配（大小写不敏感）。内容加载后展开；新增物品只要带这个 tag 就会自动进来。

### C. 建立自己的分组（想给自家武器单独的倍率）

```xml
<Group id="my_mod" label="我的模组武器" kind="weapon"
       defaultDamage="1.0" penetrationMode="add" penetrationValue="0.0">
  <!-- 档位预设（设置页 LV1/LV2/LV3 一键应用；可省略，省略后档位按钮不动这一组） -->
  <Tier level="1" damage="1.1" penMode="add" penValue="0.02"/>
  <Tier level="2" damage="1.2" penMode="add" penValue="0.05"/>
  <Tier level="3" damage="2.4" penMode="add" penValue="0.10"/>
  <Item id="my_bullet_01"/>
  <Item id="my_sword"/>
  <Tag name="my_mod_extra"/>
</Group>
```

- `kind="weapon"`（默认）或 `kind="armor"`；防具组用 `defaultDefense="1.0"`。
- 新分组会**自动出现在游戏内设置页**（左侧分组列表），玩家可自由调。
- 默认值请一律写成**中性**（`damage=1.0` / `penValue=0.0`（add）或 `1.0`（multiply）/ `defense=1.0`）——本模组的约定是"默认不增强任何数值"，强度由玩家用档位/滑条决定。

## 3. 排除物品

任意包的配置里都可以写（对显式收录与自动收录都生效）：

```xml
<DamageSettings version="1">
  <Exclude id="some_item_i_dont_want"/>
</DamageSettings>
```

## 4. 规则覆盖（可选，全局生效，谨慎使用）

```xml
<Rules>
  <DamageTypes>damage,burn,bleeding,bloodloss</DamageTypes>   <!-- 哪些 affliction 类型算“伤害” -->
  <EffectTargets>Limb,UseTarget,AllLimbs,LastLimb</EffectTargets> <!-- StatusEffect 语境只看这些目标 -->
  <DefenseReductionCap value="1.0"/>                          <!-- 防具减伤上限（1.0 = 不设限） -->
</Rules>
```

## 5. 生效与验证

| 动作 | 说明 |
|---|---|
| 启用模组 | 文件随内容包加载自动合并；**修改配置后不用重启游戏**，下一局自动重读 |
| 本机立即重读 | 控制台 `damage_reload`（设置页所在机器） / 服务器控制台 `damage_rescan` |
| 看是否合并成功 | `damage_list` 会打印「合并来源：…」，并列出每个分组的条目数与当前值 |
| 看某物品归哪组 | `damage_probe <物品identifier>`，第一行就是 `[分组] 物品`；不在此表会提示"不在任何分组中" |
| 拼错 id | 日志会告警「配置引用的物品有 N 个未在内容中找到（如：…）」 |

## 6. 语义与优先级

1. **显式清单优先**：写在任何配置里的 `<Item>`/`<Tag>` 一定会被收录（除被 `<Exclude>` 排除的）；
2. 本模组自己还会**自动收录**名字含「东方」的模组里"可补强"的物品（有武器组件或引用了白名单伤害类型的 affliction）——你的模组如果不是"东方"命名，请用上面的显式写法；
3. 同一物品出现在多个分组时，按 `turret > exclusive > general > divingsuit > hyouibana > headwear` 归并（日志会提示）；
4. 修改只会乘"白名单伤害类型"的 affliction（默认 `damage/burn/bleeding/bloodloss`），`stun`、`itemdamage` 等不动；穿甲支持加算（`add`）与乘算（`multiply`）二选一，最终封顶 0~1；防具走 `Wearable.DamageModifiers`。
